# SWE015 - Real-Time Chat Moderation

An intelligent chat moderation application using Machine Learning, Neural Networks and Quantized Transformers.

## Models
- TF-IDF + Logistic Regression
- Word2Vec + Feedforward Neural Network
- DistilBERT
- Quantized DistilBERT

## Best Model Results
- Accuracy: 96.40%
- Macro-F1: 89.41%
- Model Size Reduction: 48.21%

## Technologies
Python, PyTorch, Scikit-learn, Gensim, Transformers, Gradio.

## Application
A Gradio-based application that detects offensive messages using a Quantized Transformer.
